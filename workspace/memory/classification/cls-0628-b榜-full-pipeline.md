# GCN 完整四阶段实验 — B榜分类任务

## 数据分析发现

- B榜：7650节点，512特征（完全稠密），8分类
- 完全有向图（0双向边，0自环），出入度均为8-883
- **类别严重不平衡**：类别0(5.0%), 类别1(22.2%), 类别6(25.1%), 类别7(4.2%)
- 特征全稠密，无需稀疏处理

## 阶段一：架构筛选（6架构对比）

使用PyG原生conv层 + 无向化 + 特征z-score标准化 + 专属配置

| 架构 | val_acc |
|------|---------|
| **GCN** | **0.5507** |
| GAT | 0.4771 |
| GraphSAGE | 0.4412 |
| SGC | 0.4387 |
| APPNP | 0.3709 |
| GIN | 0.3546 |

关键改进：PyG原生GCNConv替代手工实现，无向化(A+A^T)，特征标准化。GCN大幅领先。

## 阶段二：单种子调参（前3架构网格搜索）

### GCN网格搜索（54配置）
最优：lr=0.005, hd=128, do=0.7, de=0.2, ls=0.0, wd=1e-4 → 0.5490
发现：hd=128最优（非256/512），大模型在小图上过拟合

### GAT网格搜索（~40配置）
最优：lr=0.005, hd=128, heads=8, do=0.3, de=0.3, ls=0.05, wd=1e-4 → 0.5368
关键发现：heads=8是突破（阶段一只有heads=4→0.4771），提升6个百分点
lr=0.005时do=0.5/0.7全部崩溃

### GraphSAGE网格搜索（~54配置）
最优：lr=0.008, hd=128, do=0.7, ls=0.05, wd=5e-4 → 0.4796

## 阶段三：多种子集成

### 关键问题：预测分布坍塌
GCN无CW + ls=0.0：类别7仅0.8%，类别0仅2.6%
GCN无CW + ls=0.05：类别7仍仅0.8%

### 解决方案：验证集偏置校准
在每个种子上做logit偏置校准：
- 目标分布：均匀分布(1/8)
- 校准因子clip到[-1.5, 1.5]
- 效果：类别7从0.8%→22.9%，最少类从0.8%→6.2%

### Class-Weighted GCN
使用反比频率的类别权重，val下降（0.5332）但分布健康（5.2%最少类）。

### 最终校准集成
- GCN 20种子校准集成：val mean=0.5480，最少类5.9%
- GCN 15种子校准集成：val mean=0.5490

### GAT校准集成（lr=0.003）
GAT 10种子：val mean=0.5278，但分布不健康（最少类1.8%）
跨架构集成（60%GCN+40%GAT）：最少类4.7%，不满足5%要求

## 阶段四：标签传播后处理

标签传播导致分布恶化（类别7从356→1），跳过。收益通常很小，与参考文件一致。

## 图结构特征增强

拼接6维图结构特征：log出入度、log总度数、PageRank、2-hop度数、特征范数
- 分别标准化原始特征和图结构特征后再拼接（518维）
- GCN 20种子：val mean=**0.5516**，std=0.0026
- 最少类5.7%，分布健康
- 比纯GCN（0.5480）提升0.0036

## 关键洞察

1. **偏置校准是解决类别不平衡的利器**：无需class weights（会降低val），在验证集上做logit偏置校准即可同时保持高val和健康分布
2. **GAT需要heads=8**：默认heads=4在B榜上严重不足
3. **图结构特征有效但收益递减**：6维特征提升约0.004
4. **标签传播无帮助**：在本数据集上标签传播恶化了预测分布
5. **GCN小模型更优**：hd=128优于256/512，小图容易过拟合
6. **线上分数可能仍偏低**：历史线上0.34 vs 本地0.48的巨大gap值得关注，可能存在验证集过拟合或分布偏移
