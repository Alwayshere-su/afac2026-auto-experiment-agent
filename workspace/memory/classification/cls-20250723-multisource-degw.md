## 关键突破（相比 FP+类权重 单源集成）

### 单源集成回顾
- FP K=5 + 完全类权重 + 20种子全数据训练 SWA
- 与 Agent v3 软集成 (70:30)
- 分布: C0=4.8%, C7=5.6%, min=4.8%

### 本次突破
1. **多源互补**: 两个独立训练的FP源（不同种子池 + 不同训练策略）软集成
   - 源A: 标准FP + 类权重, 40种子 (seeds 600-639)
   - 源B: FP + 类权重 + 度加权, 20种子 (seeds 700-719)
   - 源C: Agent v3 已有集成
   - 最优权重: 源A 54% + 源B 23% + 源C 23%
2. **度加权训练** (关键新增): 在类权重基础上，对低度训练节点加权 `1/sqrt(degree)`
   - 动机: 测试节点平均度19.5 vs 训练26.4。低度节点在测试集占比更高，让模型更关注它们
   - 效果: 度加权模型提供与标准模型互补的预测信号
   - 注意: 绝大多数训练节点度集中在25-30之间，度权重方差小(std=0.15)，效果是边际的
3. **多样化种子池**: 不同种子范围产生不同的集成特性
   - 少数种子(15-20)集成有"方差红利"——更进取地预测小类
   - 多种子(40+)集成更稳定但更保守

## 核心技术栈

### 多源训练
```python
# 源A: 标准训练
w = class_weights[labels]  # 仅类权重

# 源B: 度加权训练
deg_w = 1.0 / sqrt(degree[train_nodes])
deg_w = deg_w / deg_w.mean()  # 均值为1
w = class_weights[labels] * deg_w  # 类权重 × 度权重
```

### 三路软集成
```python
# 在测试集软概率层面加权平均
combined = w_nowarmup * ens_a + w_degw * ens_b + w_agent * agent_ens
# 搜索最优权重: 网格搜索 wa∈[0.18,0.30], ratio∈[0.55,0.80]
```

## 失败尝试（本系列）
1. **warmup LR**: 模型变保守，降分
2. **偏置校准 (C6=-0.20)**: 把正确C6推错
3. **kNN图增强**: 特征相似边变噪音
4. **更多种子(40→50)**: 集成更保守
5. **多K值集成 (K=3/5/7)**: Agent权重太高稀释效果
6. **标签传播平滑**: 0.40719预测已图一致,LP不动
7. **APPNP式FP**: 不如平滑式
8. **sqrt类权重**: 太弱

## 关键洞察
1. **多种子集成天然保守**: 种子越多→方差越低→对少数类预测越保守
2. **Agent是保守引力源**: Agent v3 (53种子大集成) 本身就保守，给多了稀释进取性
3. **不同种子池有不同"个性"**: seeds 200-219 碰巧更进取，seeds 600-639 更保守
4. **度加权效果边际但正向**: 训练集缺乏极低度节点，限制了度加权的效果
5. **没有银弹**: 所有改进都是边际的(+0.002)。当前架构(GCN+FP+类权重)可能接近天花板

## 未来改进方向

3. **特征工程**: 针对C7/C0节点的特异性特征
4. **更极端的类权重**: C7=3-4x 在多种子集成上可能有不同表现
5. **集成蒸馏**: 用当前集成预测作为软标签训练新模型
