# 分类任务实验记忆 — v4/v5（多样性K值+类别平衡+温度缩放）

## 日期
2025-03-20

## 关键改进（相比v3）

### v3回顾
- GCN 0.4639 best single seed, 62种子集成, 线上0.40131
- 仅使用K=5特征传播
- 偏置校准 {0:+0.4, 1:-0.4, 6:-0.6, 7:+0.4}

### v4/v5改进
1. **多样性K值特征传播**: K=3,4,5,7 多种传播步数，增加集成多样性
2. **类别平衡损失**: 训练15个类别平衡种子，显著提升少数类预测（class 0从36-43提升到68-94，class 7从7-14提升到69-138）
3. **温度缩放**: 在偏置校准前使用T=1.1-1.2的温度缩放，减少过度自信
4. **更严格的种子筛选**: 标准种子使用mean-0.3*std筛选，类别平衡种子全部保留
5. **加权集成**: 类别平衡种子2x权重，补偿少数类信号不足

## 实验流程

### v4a: improve_v4.py — 35个多样性新种子
- GCN K=3 lr=0.02 (5种子): val 0.4551-0.4739, **最佳单种子0.4739（新纪录！）**
- GCN K=4 lr=0.02 (5种子): val 0.4608-0.4657
- GCN K=5 lr=0.02 (5种子): val 0.4592-0.4657
- GCN K=7 lr=0.02 (5种子): val 0.4616-0.4681
- GCN K=5 度加权 (5种子): val 0.4575-0.4665
- GIN K=5 lr=0.02 (5种子): val 0.2704-0.4028 ❌ (lr太高)
- APPNP K=5 lr=0.01 (5种子): val 0.3562-0.3644 ❌

**结论**: GIN和APPNP在本数据集上不可用。GCN在K=3时表现最佳(最高0.4739)。不同K值种子都偏向多数类(raw class 7仅0.7%)。

### v4b-v4c: 种子筛选调试
- 发现旧种子加载有命名不匹配bug，修复后正确合并88种子
- 使用mean-0.5*std筛选得66种子，集成mean_val=0.4634
- 偏置校准：{0:+0.4, 1:-0.5, 6:-0.6, 7:+0.3}，分布4.1%-24.1%

### v4d: train_v4d.py — 类别平衡种子+温度缩放
- GCN K=3 lr=0.02 (10种子): val 0.4583-0.4665
- GCN K=5 lr=0.02 类别平衡 (10种子): val 0.4355-0.4502
- GCN K=3 lr=0.02 类别平衡 (5种子): val 0.4371-0.4469
- 共113种子，筛选93个，ensemble mean_val=0.4624
- **关键发现**: 类别平衡种子val低但少数类预测强！
  - 标准GCN: class0=36-43, class7=7-14
  - 类别平衡GCN: class0=68-94, class7=69-138
- 温度缩放T=1.2最优，偏置{0:+0.3, 1:-0.4, 6:-0.5, 7:+0.3}
- 分布: 4.5%-24.2%

### v4e: GraphSAGE尝试
- GraphSAGE 20种子 at lr=0.005/0.01/0.02: val 0.3766-0.4060
- **结论**: GraphSAGE在本数据集上完全不可用，全部低于筛选阈值
- 副作用：降低了质量阈值，导致更多低质量种子被纳入

### v4f: Correct & Smooth尝试
- 训练10个K=3 GCN种子保存全图概率: val 0.4583-0.4690
- C&S: 所有参数组合都无效（无有效配置，预测过于偏向多数类）
- LP: 同样无效
- **结论**: 图结构本身导致信息传播向多数类集中，C&S/LP在此数据集上不适用

### v5: final_v5_cb.py — 最终集成（当前最佳）
- 标准种子: 54/98 (mean-0.3*std筛选，threshold=0.4608)
- 类别平衡种子: 15/15 (全部保留)
- 加权集成: CB种子2x权重
- T=1.1, 偏置{0:+0.2, 1:-0.3, 6:-0.4, 7:+0.1}
- **偏置更温和**（相比v3的{0:+0.4, 1:-0.4, 6:-0.6, 7:+0.4}），更依赖模型自身信号
- 分布: {0:74(4.8%), 1:338(22.1%), 2:131(8.6%), 3:225(14.7%), 4:191(12.5%), 5:140(9.2%), 6:363(23.7%), 7:68(4.4%)}
- 最少类4.4% ≥ 3% ✓，最多类23.7% ≤ 30% ✓

## 关键洞察

1. **类别平衡损失是关键突破**: 虽然val低0.02，但少数类预测量是标准种子的2-3倍。必须保留这些种子并用更高权重。
2. **K=3特征传播最优**: 最高单种子0.4739（新纪录！），比K=5的0.4690高0.005
3. **GIN/GraphSAGE/APPNP均不可用**: 在此数据集上val远低于GCN，无法贡献有效信号
4. **C&S/LP无效**: 图结构导致信息传播向多数类集中
5. **温度缩放有帮助**: T=1.1-1.2轻微减少过度自信，减少偏置校准强度
6. **更温和的偏置更好**: v5偏置幅度(vs v3)从{0.4,0.4,0.6,0.4}降到{0.2,0.3,0.4,0.1}，更依赖模型信号
